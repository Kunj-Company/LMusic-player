# Security policy

## Supported versions

Only the latest release on the [Releases](https://github.com/Kunj-Company/LMusic-player/releases) page gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report it privately instead:

1. Go to the [Security tab](https://github.com/Kunj-Company/LMusic-player/security) and click **Report a vulnerability**, or
2. Email **abhiramnj@gmail.com** with "LMusic security" in the subject.

Include what the problem is, how to reproduce it, the LMusic version and your device. You'll get a reply within about a week. Once a fix is released, you'll be credited in the release notes unless you'd rather not be.

## What counts

Things like: leaking a user's files, account cookies (YouTube Music or JioSaavn sign-in) or listening history; another app being able to control LMusic or read its data; the release signing setup; anything that lets an APK impersonate LMusic.

Problems with YouTube Music or JioSaavn themselves should go to those services.
